# PACT

[![ArXiv](https://img.shields.io/badge/ArXiv-2026-red.svg)](https://arxiv.org/abs/2606.22378)

This repository contains the official implementation of the paper "**Following the Flow: Advection-Consistent Modeling for Event-based Small Object Detection**".
The manuscript has already been accepted with ECCV 2026.

## Code Release

The source code, pretrained models, and more details will be released on **September 1, 2026**.
